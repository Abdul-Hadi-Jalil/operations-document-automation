# Integration boundaries

## Work-management API

Supports project discovery, recent-ticket queries, issue detail extraction, and rich-text normalization.

## Google Drive

Uses OAuth authorization to traverse folder trees, identify matching spreadsheets, and download authorized files.

## Staff-planning portal

Uses a controlled browser session for authenticated export where no direct API is available.

The public showcase omits tenant URLs, project keys, folder identifiers, selectors, and customer naming.
